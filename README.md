# CenC — CNC Bewerkingen Gardemoen

Website voor CNC-freesdiensten op basis van de **Multicam 3000**.  
Gericht op de regio Gardemoen (Noorwegen) — particulier en industrieel.

## Diensten

- CNC-frezen op maat (hout/MDF, aluminium, kunststof/acryl)
- Tekenhulp & CAM-voorbereiding (schets → DXF/G-code)
- Kleine lokale bezorgservice
- Standaard freeswerk & maatwerk prototyping

## Techniek

Statische website — geen backend, geen framework.  
Werkt direct via GitHub Pages.
